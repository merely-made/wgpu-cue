# Shared contract implementation proof — 2026-10-22

This receipt records the first contract and two concrete producer adapters.
It does not qualify a product migration or all four engines. The implementation
lives in the standalone `wgpu-cue` repository, with a separate renderer-free
`webcue` package. Every package is unpublished and has `publish = false`.

## Findings kept visible

- The synchronous `RenderCore::try_rasterize_scaled_for` path can wait up to
  five seconds. The adapter instead submits through Netrender and polls
  deferred quality results; ordinary presentation has no GPU wait. On error
  it discards the pending target. Drawing and quality polling on that
  RenderCore must remain exclusive to the proof adapter. Shared renderer
  quality attribution across multiple independent adapters remains open.
- Genet's retained input result includes capture and editable-focus hints;
  the shared event preserves them. The proof exercises retained IME state,
  not a platform candidate window. The CJK fixture emitted an ICU4X warning
  about a missing segmentation model; the IME commit and semantic value
  assertions still passed. No CJK segmentation claim follows from that test.
- Scry's WKWebView producer supplies no navigation IDs. `Reply::Dispatched`
  acknowledges dispatch; navigation completion remains a separate ordered
  observation. Script requests do have correlated supplier IDs.
- The first WK proof waited for editable/caret events and failed that
  expectation. Source inspection confirmed that the current WK producer does
  not emit them. The final proof asserts DOM focus via script and explicitly
  reports no caret observation. The typed forwarding path preserves such
  events when a supplier actually emits them; it is not evidence of WK support.
- The first translucent-pixel assertion assumed premultiplication and failed.
  The observed bytes established straight alpha; the adapter metadata and
  regression assertion now agree with those bytes. Retaining the failed
  expectation prevents an assumed convention from becoming a claim.
- Native Scry frame conversion and Metal synchronization compile, including
  explicit refusal of missing shared events and unsupported formats/sync.
  ScreenCaptureKit capture was not started or qualified. The native fixture
  proves custody/import mechanics independently of the CPU WebKit example.
- The shared contract represents retained snapshots and ordered AccessKit
  tree updates separately. Only Genet's retained semantic protocol is exercised
  by a live producer here; no CEF/Servo tree adapter or OS bridge is qualified.
- No Turnstone, Pelt, Graphshell or Inker consumer has been migrated. CEF and
  Servo adapters, per-card/site routing, native accessibility bridges and
  candidate-window placement remain integration work. The crate is not yet
  a general shared-renderer Genet production adapter.

The pre-existing primary checkouts were left alone. All supplier edits were
made in clean isolated worktrees, committed to separate branches, and checked
for unrelated changes. Mere's assessment and concurrent upstream/dependency
work were not edited by this implementation.
